# KIRARA MUSE — データ追加ガイド

## 作品を追加する手順

### 1. 画像を配置する
`assets/works/` フォルダに画像ファイルを入れる。
ファイル名は `work001.jpg` の形式で連番にする。

```
assets/works/
├── work001.jpg
├── work002.jpg
├── work007.jpg   ← 新しく追加する場合
└── ...
```

### 2. works.json に追記する
`data/works.json` を開いて、末尾の `]` の前に以下のテンプレートをコピーして追記する。

---

## 作品データ テンプレート

```json
{
  "id": "work007",
  "title": "作品タイトル",
  "grade": "小学3年生",
  "theme": "自然・海",
  "themeEn": "Nature / Sea",
  "desc": "作品の説明文。どんなことを思って描いたか、どこが工夫したポイントかなど。",
  "tags": ["タグ1", "タグ2", "タグ3"],
  "image": "assets/works/work007.jpg"
}
```

---

## フィールド説明

| フィールド | 必須 | 説明 |
|-----------|------|------|
| `id`      | ✓ | 一意なID。`work` + 3桁連番（例: work007） |
| `title`   | ✓ | 作品タイトル |
| `grade`   |   | 学年（例: 小学1年生、小学6年生） |
| `theme`   | ✓ | テーマ。絞り込みタグに使用される |
| `themeEn` | ✓ | テーマの英語表記（カード上部に表示） |
| `desc`    |   | 作品説明文（1〜2文） |
| `tags`    |   | タグの配列。カード下部に小さく表示 |
| `image`   | ✓ | 画像パス。空文字 `""` にすると「画像準備中」表示 |

---

## テーマ一覧（現在使用中）

テーマは自由に追加できるが、以下を参考に統一すると絞り込みが見やすくなる。

- `自然・海`
- `自然・花`
- `どうぶつ・生きもの`
- `くらし・まち`
- `ファンタジー`

---

## 追記例（works.json 末尾に追加するイメージ）

```json
[
  { ...既存の作品... },
  { ...既存の作品... },
  {
    "id": "work007",
    "title": "雨の日の水たまり",
    "grade": "小学2年生",
    "theme": "自然・海",
    "themeEn": "Nature",
    "desc": "雨上がりに空が映り込んだ水たまりを見て、もう一つの世界みたいだと思いました。",
    "tags": ["雨", "水", "自然", "空"],
    "image": "assets/works/work007.jpg"
  }
]
```

> **注意**: JSONはカンマの付け忘れ・付けすぎに注意。
> 最後の要素の後にカンマを付けるとエラーになる。
